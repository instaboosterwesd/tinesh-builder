# Remix of Buildy Request Hub

देखो, आप एक काम करो, एक website create करो like builder name से। तो उसमें आप properly function रखना कि एक dashboard रहेगा and वहां पर UIs वगैरह दिखेंगे। तो वहां पर मान के चलो build पर कोई बंदा click करता है। by default ऐसा रहेगा, जैसे कि admin panel रहेगा, /admin से admin तो login page दिखेगा। Login page पर password देव देव डालेंगे तो login हो जाएगा। उसके बाद अंदर dashboard हो गया and builder request हो गया and एक template हो गया तो add template पर जाएंगे and add HTML, HTML add कर देंगे। तो नाम दे देंगे and उस HTML का image डाल देंगे, image upload कर देंगे और video upload कर देंगे। तो जो normal user side तो क्या देखेगी? Video दिखेगी या फिर उस पर click करेगा तो video या फिर and photo। तो build request वह डाल देगा। Build request पर click करेगा तो ऐसा होगा कि जो हमारा admin है, उसके बाद build request request आएगी। अगर उसने approve कर दिया तो उसका APK build होना शुरू हो जाएगा। बस ऐसा एक logic है and इसके लिए आपको मेरे को suggest कर देना है कि मैं GitHub का workflow use करूं। आप total frontend design करो, backend का भी design करते हैं। And आप neat and clean UI, आप red and dark use कर सकते हो या फिर जो भी आपको अच्छी लगेगी, properly icon, image, toast and जो भी सारी चीजें होती हैं properly आप add करना। ठीक है।
